# TP2-WEB

Trabajo práctico: aplicación web con **Blazor Server (.NET 8)** y **Entity Framework Core** con SQL Server.

## Entidades
- **Categoría** (1) → (N) **Producto**
- **Proveedor** (1) → (N) **Producto**

## Funcionalidades
- CRUD completo de Categorías, Proveedores y Productos
- Validaciones con DataAnnotations
- Confirmación antes de eliminar
- Interfaz con Bootstrap

## Tecnologías
- .NET 8 / Blazor Web App (render mode Server)
- Entity Framework Core 8 (Code First + migraciones)
- SQL Server
- Bootstrap 5 y Bootstrap Icons
